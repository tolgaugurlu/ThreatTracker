# ThreatTracker

Bu proje, siber güvenlik tehditleri ve zafiyetleri takip etmek için geliştirilmiş bir uygulamadır.

## Özellikler
- Gerçek zamanlı tehdit takibi
- Güvenlik açıkları analizi
- Raporlama ve bildirim sistemi

## Kurulum
Projeyi yerel makinenizde çalıştırmak için:

```bash
git clone https://github.com/tolgaugurlu/ThreatTracker.git
cd ThreatTracker
```
